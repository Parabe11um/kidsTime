# KidsTime

Адаптивный веб-сервис для поиска мест и мероприятий для досуга с детьми в Москве.

Первый вертикальный срез: карточки хранятся в PostgreSQL/PostGIS, выводятся на главной, в каталоге, на детальной странице и на карте. Визуальная основа — переданные макеты Figma: коралловый градиент, компактные фильтры, карточки-подборки и mobile-first навигация.

## Быстрый локальный запуск

Команды ниже **изменяют только локальные Docker-контейнеры, локальную базу и файл `.env`**. GitHub и внешние серверы не изменяются.

```bash
cp .env.example .env
docker compose up --build
```

После запуска:

- приложение: http://localhost:8000/
- админка: http://localhost:8000/admin/

При первом старте применяются миграции и идемпотентно загружаются демонстрационные карточки. Это явно отмечается в логе как `MODE=APPLY`.

Создать администратора:

```bash
docker compose exec web python manage.py createsuperuser
```

## Проверки

```bash
make check
make test
make seed-dry
```

`make seed-dry` работает в режиме `MODE=DRY-RUN`: показывает результат наполнения и откатывает изменения.

## Карта

Для показа Яндекс Карты укажите `YANDEX_MAPS_API_KEY` в `.env`. Без ключа каталог, карточки и координаты продолжают работать, а экран карты показывает понятное сообщение о локальной настройке.

## Что намеренно не входит в первый срез

- встроенное построение маршрута;
- оплата и билеты;
- отзывы и рейтинги;
- сложные рекомендации;
- автоматический геокодинг и сохранение данных Яндекса.

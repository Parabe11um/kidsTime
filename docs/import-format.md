# Импорт мероприятий

Контур импорта отделён от публичного каталога:

1. Источник или будущий адаптер формирует JSON.
2. Команда проверяет записи и помещает их в «Очередь импорта».
3. Редактор сверяет данные с первоисточником.
4. Действие «Создать или обновить черновики» переносит проверенные поля, площадку и сеансы в каталог.
5. Публикация выполняется редактором отдельно.

Так ошибки разметки источника, устаревшие цены и неверные даты не появляются на сайте автоматически.

## Формат файла

Корневой элемент — массив или объект с массивом `events`. Обязательны `external_id` и `title`.

```json
{
  "events": [
    {
      "external_id": "event-42",
      "title": "Научная ёлка",
      "short_description": "Интерактивная программа для детей",
      "description": "Описание из разрешённого источника",
      "source_url": "https://example.com/events/42",
      "venue_name": "Музей науки",
      "address": "Москва, Примерная улица, 1",
      "district": "ЦАО",
      "metro": "Охотный Ряд",
      "latitude": 55.7558,
      "longitude": 37.6176,
      "category": "museums",
      "organizer": "Музей науки",
      "age_from": 6,
      "age_to": 12,
      "price_from": 900,
      "price_to": 1500,
      "is_free": false,
      "duration_minutes": 90,
      "activity_format": "indoor",
      "sessions": [
        {
          "starts_at": "2026-12-20T12:00:00+03:00",
          "price": 900,
          "availability": "available",
          "booking_url": "https://example.com/events/42/tickets"
        }
      ],
      "images": [
        {
          "url": "https://example.com/image.jpg",
          "rights_note": "Предоставлено организатором"
        }
      ]
    }
  ]
}
```

Внешние изображения не скачиваются автоматически. Ссылка и сведения о правах сохраняются для проверки, после чего редактор загружает разрешённый файл в карточку мероприятия.

## Запуск

Сначала создайте источник в админке и задайте ему уникальный «Код парсера», например `museum-feed`.

Проверка без записи в базу:

```bash
docker compose exec web python manage.py stage_events /app/import/events.json \
  --source museum-feed --dry-run
```

Добавление в очередь модерации:

```bash
docker compose exec web python manage.py stage_events /app/import/events.json \
  --source museum-feed
```

Команда выводит `MODE=CHECK` или `MODE=APPLY` и итоговый `SUMMARY`. Повторный импорт того же `external_id` обновляет запись в очереди, а не создаёт дубль.

После импорта откройте в админке раздел «Очередь импорта», проверьте нормализованные данные и примените действие «Создать или обновить черновики из выбранных записей». Созданная площадка и мероприятие остаются неопубликованными, пока редактор не подтвердит их отдельно.

Перед созданием сетевого парсера для конкретного сайта нужно проверить его условия использования и зафиксировать разрешение в карточке источника. Флаг «Автоматический сбор разрешён» по умолчанию выключен.

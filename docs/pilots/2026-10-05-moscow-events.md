# Пилот источников детских мероприятий — 5 октября 2026

## Ограниченный повторяемый сбор программы музея

`import/collect_shm_pilot.py` вручную читает только одну страницу программы, один раз,
без изображений, описаний и цен. Он пишет JSON для просмотра и не меняет базу:

```bash
python3 import/collect_shm_pilot.py \
  --from-date 2026-10-06 --days 14 \
  --compare import/pilot_shm_2026-10-05.json \
  --output import/shm_candidates_2026-10-06.json
```

Если структура страницы изменится или сайт вернёт пустой список, файл не записывается.
Проверяйте число найденных записей, площадку каждого сеанса и даты по первоисточнику.
Сейчас у источника `shm-manual-pilot` автоматический сбор отключён; эта команда
не запускается по расписанию. Не отправляйте результат в `stage_events` до проверки
отчёта и локального теста защиты существующей очереди.

## Ограничения перед регулярным сбором

- На [странице условий музея](https://shm.ru/ispolzovanie-materialov-sayta/) сказано, что коммерческое использование материалов требует официального запроса. До решения этого вопроса оставляем `automated_collection_allowed=false`, не копируем фотографии и описания и не запускаем сетевой сборщик.
- У Telegram-поста может не быть отдельной площадки и точного сеанса. Использовать канал для поиска кандидатов, затем подтверждать данные на сайте организатора; с историей произвольных каналов Bot API напрямую не работает.
- Временные предложения, мероприятия за пределами Москвы и абонементы требуют отдельной модели/редакторского решения. Не заполнять выдуманными координатами, возрастом, стоимостью или временем.
- Формальная команда `stage_events --dry-run` требует существующей карточки `Source` и запущенного Django с БД. В этой рабочей среде нет Docker и Django, поэтому проведена автономная проверка JSON, но команда приложения здесь не запускалась.

## Следующий технический шаг

# ADR-0001: модульный Django-монолит для MVP

- Статус: принято
- Дата: 2026-09-05

## Контекст

KidsTime должен быстро проверить ценность курируемого каталога детского досуга. На первом этапе важнее SEO, административная панель, качество данных и геопоиск, чем независимое масштабирование frontend и backend.

## Решение

Использовать Django 5.2 LTS с серверным HTML, PostgreSQL 17 + PostGIS, Tailwind CSS и небольшими изолированными JavaScript-модулями. Redis/Celery оставляются для импортов и фоновых работ. Карта работает через Yandex Maps JavaScript API v3, а маршрут в MVP открывается внешней ссылкой в Яндекс Карты.

Координаты каталога поступают от организаторов и редакторов либо выбираются кликом по карте. Результаты Геокодера не сохраняются без подходящей лицензии.

## Последствия

- Один репозиторий и один контур авторизации.
- Быстрый запуск административного интерфейса и SEO-страниц.
- Возможность перейти к отдельному API или frontend-приложению позже без преждевременного усложнения MVP.

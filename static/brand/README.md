# KidsTime wordmark

`kidstime-logo.svg` is the unchanged vector export from the KidsTime Figma file:

- File: `xhs5kKoQK1fVams7ihxY8R`
- Desktop page: `115:2067`
- Homepage: `126:1734`
- Header logo group: `I631:11295;157:1772`
- SVG bounds: `133 × 28`, `viewBox="0 0 133 28"`
- Exported as SVG on 2026-10-16 (Europe/Moscow).

The asset contains eight outlined paths and no text or external fonts. It is used
as a CSS mask, following the existing navigation-icon convention. This preserves
the original geometry and SVG dimensions while allowing the existing white,
coral and ink colors in different interface slots.

Call sites use `templates/includes/brand_mark.html`: desktop header, footer,
account screens and guest profile. Do not replace the outlines with styled text.
